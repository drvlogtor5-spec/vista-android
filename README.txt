ویستا | Vista — نسخه نمایشی قابل اجرا

روش ساده:
1) فایل ZIP را استخراج کن.
2) فایل index.html را دوبار کلیک کن تا در مرورگر باز شود.
3) می‌توانی پست آزمایشی بسازی، عکس و ویدئوی کمتر از ۶۰ ثانیه انتخاب کنی، لایک و نظر بدهی، در بخش پیام‌ها پیام آزمایشی بفرستی و دستیار نمایشی را امتحان کنی.

نصب به شکل برنامه (PWA):
برای نصب و حالت آفلاین، پروژه را روی یک وب‌سرور HTTPS یا localhost اجرا کن. باز کردن مستقیم index.html امکان نصب PWA را فعال نمی‌کند. اگر Python نصب است، در همین پوشه اجرا کن:
  python -m http.server 8000
سپس در مرورگر برو به http://localhost:8000 و از منوی مرورگر Install app / Add to Home Screen را بزن.

محدودیت مهم:
این یک نمونهٔ فرانت‌اند و نمایشی است. پست‌ها و پیام‌ها به سرور ذخیره نمی‌شوند؛ فایل‌های انتخاب‌شده با URL محلی نمایش داده می‌شوند و ممکن است پس از بستن صفحه از دست بروند. ورود/ثبت‌نام واقعی، چت بلادرنگ بین دستگاه‌ها، ذخیرهٔ ابری، امنیت/مجوزها و هوش مصنوعی واقعی هنوز به بک‌اند و سرویس‌هایی مانند Supabase، فضای ذخیره‌سازی ابری و کلید API سمت سرور نیاز دارند. هیچ کلید محرمانه‌ای در این پروژه قرار داده نشده است.
